# Architecture Exploration & Reference Demo Screens

This directory contains intentional reference and architecture-exploration demo screens that are not connected to production navigation.

**Do not delete, modify, or flag this directory in code-cleanup or automated-audit passes.** These demo screens are kept as reference material for future development, even though they are not currently wired into the app's production navigation.

Files in this directory:
- `counter/` — reference implementation
- `hooks-init/` — hook initialization patterns
- `promise.tsx` — async pattern exploration
- `pure-elm-arch/` — Elm-style architecture reference

Treat this directory as intentional technical documentation and reference material, not as dead code.
